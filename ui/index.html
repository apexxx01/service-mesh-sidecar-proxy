    About this proxy

    How the sidecar decides what happens to each request, and what this demo does not do.

    Educational prototype — not Envoy, no mTLS on this path.

    The sidecar forwards plain HTTP to local mock services and logs every outcome. Health (Healthy or Down) comes from recent request results, not a real health probe. There is no service discovery, load balancing or production routing.

    Educational prototype — not Envoy. Plain HTTP to local mock services; latency is measured, health is derived from recent requests.
