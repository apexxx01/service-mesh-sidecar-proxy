About this proxy

Educational mock — not Envoy. The sidecar forwards plain HTTP to local mock services and logs every outcome. Latency is measured; health (Healthy or Down) comes from the last requests, not a real health probe.

  • Forward: GET and POST pass through with a timeout (504 if exceeded).
  • Block: a path in blockedPaths gets 403 and is never forwarded.
  • Drain: a drained upstream gets no new traffic; requests return 503 "drained".
  • Bonus beyond the PRD: real mTLS between sidecars and a circuit breaker. Not used for production routing.
