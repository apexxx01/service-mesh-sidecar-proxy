# Wireframes

Low-fidelity, greyscale wireframes for all 7 PRD screens. Web screens are shown at laptop (1440) and phone (390) width; the two app screens are Expo Go at 390.
Source file: [Figma - Mini Envoy Wireframes](https://www.figma.com/design/OxPbxbhEhenQSyLo4TYX0o)

Grey square = icon placeholder. Status is always icon + text, never colour alone. Dashed boxes describe UI states (loading, empty, no results, errors).
